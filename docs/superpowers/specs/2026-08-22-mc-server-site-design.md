## 站点架构

```
MoeDawn.github.io/
├── index.html        # 单页结构：Hero → 服务器列表 → 历史档案馆 → FAQ → 页脚
├── css/style.css     # 全部样式；CSS 变量定义双主题
├── js/servers.js     # 服务器数据（开放中 + 历史服数组；更新服务器只改此文件）
├── js/main.js        # 主题切换/大纲/状态查询/动效/彩蛋
└── images/           # 语雀图片本地化
```

推送 `main` 分支即通过 GitHub Pages 发布至 `https://moedawn.github.io`（若 Pages 未启用，部署环节开启）。

## 视觉设计

**深色模式（默认）— 暗夜霓虹**：深蓝黑底 `#0b0e1a`；主强调色霓虹青绿 `#7ef0c3`；辅助电光蓝 `#4ea8ff`。玻璃拟态卡片（半透明 + backdrop-blur + 细边框）、霓虹光晕按钮、深色渐变背景。

**亮色模式 — 粉白紫（4:4:2）**：底色以白 + 浅粉柔和渐变为主（约 40% 白 + 40% 粉），紫色 `#8b5cf6` 系占 20% 作强调（按钮、链接、高亮）。樱花粉紫的柔和感，与深色模式形成反差。

两套主题全部通过 CSS 变量（`--bg`、`--accent`、`--card` 等约 15 个）驱动。默认跟随系统，右上角按钮手动切换，选择存 localStorage。字体用系统字体栈（中文渲染好、零加载）。

## 页面结构（自上而下）

1. **Hero 英雄区** — 服务器名「脑溢血急救中心」+ 副标语 + 手写 CSS 徽章排：「加入 QQ 群」（跳群链接）、「1.21.11 生存服 · 在线」等实时状态徽章；CSS 动画渐变光晕背景
2. **服务器列表** — 表格：名称 | 版本 | 类型 | 地址（复制按钮）| 整合包 | 在线状态（绿点+人数）。仅开放中的 2 个服
3. **历史服档案馆** — 默认折叠（`<details>`），收录 7 个已关闭服务器 + 简述，老玩家回忆墙
4. **FAQ 长文档** — 迁移语雀全部内容并重排版，标题锚点化：服务器介绍 / 正版验证·白名单·地址 / 启动器推荐（PCL2）与整合包安装 / Java 版 vs 基岩版 / 手机游玩。含彩蛋②"文本和链接太多了，我不想看怎么办"
5. **页脚** — 加群徽章重复 + 版权 + 彩蛋①③

**常驻大纲**：桌面端右侧吸顶竖排目录，可点击收起；手机端为顶部悬浮"目录"按钮，点开抽屉式目录。滚动时当前章节高亮。

## 源数据疑点（实现时处理规则）

**用户已确认为最新的服务器状态（2026-08-22）**：开放中仅 2 个 — ① 1.21.11 服务器，地址 ssjj2.top，无正版验证；② 亡者世界整合包，版本 1.20.1，无正版验证，地址 ssjj3.top。重度机械症航空学已关停，转入历史档案馆。原文的"26.2 纯生存服"（ssjj3.top）即亡者世界服的前身。

语雀原文中同一服务器的版本号前后不一致（如重度机械症在列表览写 1.20.1、地址节写 1.21.1、末节写 1.21.11）。处理规则：**以用户最新确认为准，其次以"服务器地址"一节为权威来源**。白名单需群内找管理员上报游戏 ID。

## 明确不做（YAGNI）

- 不做多页路由 / 服务器详情子页（内容膨胀后再说）
- 不引任何第三方运行时依赖（Tailwind CDN、Alpine 等，用户已知悉利弊后选定纯原生）
- 不做评论、统计、后端功能
- 不做 SEO 深度优化（单页群宣传站，基础 meta 即可）
